# Stickers

The Stickers tab's 103 original marks, drawn as SVG by `tools/stickers.mjs` and rendered to transparent
PNG by headless Edge (`node tools/stickers.mjs`; the export engine reads PNG). CC0 1.0. Makers, units,
lot and serial numbers are fictional.

Categories: Receiver (roll marks), Controls (selector / sight markings), Proof (proof and inspection
stamps), Part Stamps, Data Plates, Ordnance (ammo and explosive containers), Military (equipment
stencils), Industrial (safety signs). In `index.json` an `engrave` depth makes a sticker start engraved
(cut-metal tint); `tint: #ffffff` keeps a coloured sign's palette; no tint = the brush colour.

Glyphs: the SIL OFL faces in `tools/fonts/`.
