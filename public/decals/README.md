# Decals

Original transparent PNG decals for Van Gogh, drawn by `tools/decals.py`.
CC0 1.0: free for commercial work, no attribution required. Tint them in the Decal layer
settings; coloured signs (hazard, danger, neon) ship with their own palette.

The generator uses the SIL OFL fonts in `tools/fonts/` (Barlow Condensed, Share Tech Mono,
Allerta Stencil, M PLUS 1p), so the rasterised marks and the tooling are redistributable.
