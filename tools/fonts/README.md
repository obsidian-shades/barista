# Decal fonts

These faces are used only to draw `public/decals/*.png`; the decals themselves are CC0.
The font files stay under the SIL Open Font License 1.1 (see the `OFL-*.txt` files beside them).

| File | Family | Source |
| --- | --- | --- |
| `BarlowCondensed-Bold.ttf`, `BarlowCondensed-ExtraBold.ttf` | Barlow Condensed | [Google Fonts](https://fonts.google.com/specimen/Barlow+Condensed) |
| `ShareTechMono-Regular.ttf` | Share Tech Mono | [Google Fonts](https://fonts.google.com/specimen/Share+Tech+Mono) |
| `AllertaStencil-Regular.ttf` | Allerta Stencil | [Google Fonts](https://fonts.google.com/specimen/Allerta+Stencil) |
| `MPLUS1p-Bold.ttf` | M PLUS 1p | [Google Fonts](https://fonts.google.com/specimen/M+PLUS+1p) |

`python tools/decals.py` regenerates the PNGs and their manifest.
